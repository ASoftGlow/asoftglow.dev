This was one of my first projects, using Python with pillow. I've ported it to Javascript and HTML5 canvas for the web. It's certainly not perfect, but it's good enough to be useful.

The current cat's parameters are stored in the global variable cat if you wish to save them.

Note: Browsers may randomize the canvas to help reduce fingerprinting, which will break this tool and cause red pixels to remain.
