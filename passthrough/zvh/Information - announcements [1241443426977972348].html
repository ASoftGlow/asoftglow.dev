Chris [Redstone5010] 7/23/2024 3:58 AM

Beta 0.2.0

Here’s a recap of the changes done to the game within the past few weeks. If you’ve been keeping up with the game for a while, then most of this will not be new. @Update Ping
  • Added the Creeper class. It’s strong, but very committal. It costs 8 coins and explodes with a blast radius that is 50% larger than TNT
  • Added a modifier voting menu that appears every other game
  • Added the Scatter modifier
  • Added support for level requirements for classes
  • Added revival mechanic—kill 3 humans to become human again
  • Made it so the map size is reduced if 3 or less people are playing
  • Minor map decoration additions
  • Changed Unexplodable Wool to netherrack instead of red wool
  • Changed how spawn protection works so that resistance is given to players instead of blocking attacks near spawn using an entity
  • Reworked the Fortress modifier
  • Fixed bugs relating to winning team display at the end of a game
  • Minor buffs to the fishing rod item
- Added block cosmetics—select by running /cosmetics (edited)
